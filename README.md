# WordPad Lite — 実装メモ

WordPad Lite は 2 つの実装で構成されています。

- **ネイティブ版（WinUI 3）** — `WordPadLite.WinUI/`。Word 風リボンを備えた Windows デスクトップ アプリ。
- **Web 版（ASP.NET Core）** — `WordPadLite/`。従来のブラウザ版で、そのまま利用できます。

---

# ネイティブ版（WinUI 3）

## 概要

Windows App SDK / WinUI 3 によるアンパッケージ（自己完結）デスクトップ アプリです。
日本語 UI の Word 風リボンと、A4 ページ表示のリッチ テキスト エディタを備えています。

## 動作環境

- Windows 10 バージョン 1809（ビルド 17763）以降 / Windows 11
- .NET 10 SDK（ビルド時）
- Visual Studio 2022 以降の Windows アプリ開発ワークロード（推奨）

## ビルドと起動

```powershell
cd WordPadLite.WinUI
dotnet build -c Debug -p:Platform=x64
```

実行ファイル:

```
WordPadLite.WinUI\bin\x64\Debug\net10.0-windows10.0.19041.0\win-x64\WordPadLite.exe
```

Windows App SDK は自己完結で出力されるため、追加のランタイム インストールは不要です。

## 主な機能

### リボン / UI
- Word を踏襲したタブ構成: ファイル / ホーム / 挿入 / デザイン / レイアウト / 参考資料 / 差し込み文書 / 校閲 / 表示 / ヘルプ
- **従来のリボン（既定）** — Word と同じグループ名付きの 2 段リボン。グループ右下の「↘」から詳細設定（準備中）を開けます。
- **簡易リボン** — 高さ 1 行のコンパクトなリボン。タイトル バーの「…」→「簡易リボン / 従来のリボン」でいつでも切り替えられます（選択は `%LOCALAPPDATA%\WordPadLite\ribbon-mode.txt` に保存）。
- リボンの折りたたみ（タブ右端の「^」、または「…」メニュー）。折りたたみ中にタブを押すと展開します。
- **カスタマイズ可能なクイック アクセス ツール バー** — 既定は 保存 / 元に戻す / やり直し。タイトル バーの「…」メニューからコマンドを追加・削除できます（設定は保存されます）。
- **タイトル バー** — Word と同じ `文書 1 - WordPad Lite` 形式。未保存の変更はタイトル横の小さなドットで控えめに表示します。左上には自動保存スイッチと QAT をコンパクトに配置。タイトル バーはライト / ダークを問わず常に Word ブルーで、回路風パターンなどの装飾は重ねません。右側のウィンドウ コントロールの左にはユーザー アイコンがあり、クリックするとアカウント ページが開きます。
- **ファイル タブ** — 選択状態にかかわらず Word と同じ濃いブルーで表示。
- **スタイル ギャラリー** — Word 風の横長プレビュー（標準 / 行間詰め / 見出し 1）。右端の「▼」から見出し 2 / タイトルも選べます。
- **適用中のリボン項目を強調** — 太字・斜体・下線・配置・スタイルなど、現在の選択範囲に適用されている書式をボタンの強調表示で確認できます。
- **テーマ選択** — システム / ライト / ダーク。表示タブの「テーマ」グループ、またはオプションの「外観」から切り替えられます。ダーク テーマでも用紙は常に白です。
- Word ブルー（#0F6CBD）を基調としたアクセント、カテゴリ別に色分けした Fluent アイコン、Mica 背景
- **編集 / 校閲 / 読み取り専用モード** — タブ列右端の「編集 ▾」ドロップダウンで切り替え。現在のモードはステータス バーにも表示されます。読み取り専用中に書式を変更しようとすると、編集モードへの切り替えを促すメッセージを表示します。
- **オン / オフ系コマンドの状態表示** — ルーラー、グリッド線、スペルチェック、校閲モード、編集の制限、閲覧モード、テーマなどは、リボン ボタンの背景色・アクセント下線・アイコン色で有効状態を示します。
- ファイル バックステージ（情報 / 新規 / 開く / 保存 / 名前を付けて保存 / 印刷 / エクスポート / アカウント / オプション / 終了）。表示中は Word と同じくタイトル バーが濃いブルーになり、QAT と自動保存スイッチは隠れます。左側の各項目は行全体をクリックできます。情報ページは必要最小限の項目に整理しています。
- **アカウント ページ** — ローカル ユーザー名と、WordPad Lite の製品情報（バージョン / 実行環境 / 保存形式 / ライセンス）を同じページ内に表示します（独立した「バージョン情報」ダイアログは廃止）。サインインや Microsoft 365 は不要です。プロフィールは自由に編集でき、名前・役職・画像をこの PC 内に保存します（「画像を変更」で任意の画像を丸アイコンに、「既定に戻す」で初期状態に戻せます）。
- ステータス バー（ページ / 文字数 / 言語 / 校正 / モード / ズーム）。操作結果や状態変化のメッセージはこのステータス バーに表示されます。
- **水平ルーラーと縦ルーラー** — 入力可能な本文領域を色付きの帯で表示し、余白部分は淡い網掛け、本文領域との境界はアクセント色の線で区切ります。表示タブで切り替え可能。
- グリッド線の表示切り替え
- **通知** — 通常のメッセージはステータス バーに表示して一定時間で消えます。ポップアップ（トースト）はオプションで有効にでき、既定ではオフです。エラーだけは常にポップアップで通知します。
- リボン・バックステージには控えめな表示アニメーションを付けています。
- アイコン ボタンのホバー時コントラストを改善

### エディタ
- 日本語 IME 対応のリッチ テキスト入力
- 太字 / 斜体 / 下線 / 取り消し線 / 下付き / 上付き
- フォント / サイズ / 文字色 / 背景色（ハイライト）
- 段落揃え / 箇条書き / 番号付け / インデント / 行間
- 検索 / 置換（Ctrl+F / Ctrl+H）
- ズーム（Ctrl+ホイール / ステータス バーのスライダー / Ctrl+0 で 100% に戻す）
- ドラッグ＆ドロップでファイルを開く
- 用紙設定（A4 / B5 / Letter / Legal、縦横、余白）
- **ヘッダー / フッター / 脚注のインライン入力** — ダイアログを開かず、挿入位置にプレースホルダーを選択状態で挿入します。そのまま本文上で入力できます（ヘッダーは先頭、フッターと脚注は末尾に配置）。

### 校正 / 文字カウント
- **文章校正ウィンドウ** — 校閲タブの「文章校正」で右側に Word のエディター風パネルを表示します。校正スコア、修正点の件数と一覧、表現や表記上の考慮点、校正言語、スペルチェックの切り替えをまとめて確認できます。
- **スペルチェック** — 既定でオン。赤い波線の付いた語を右クリックして候補を選べます。設定は保存されます。
- **文字カウント** — 校閲タブの「文字カウント」で、ページ数 / 単語数 / 文字数（スペースあり・なし）/ 段落数 / 行数に加え、文の数と 1 文あたりの平均文字数を表示します。ステータス バーの文字数も編集に追従して更新されます。

### 自動保存
- タイトル バー左側（アプリ ロゴの右）のスイッチでオン / オフを切り替えられます。スイッチのトラック内に「オン / オフ」の文字を表示し、現在の状態がひと目で分かります。
- オンにすると変更を一定間隔（既定 30 秒、オプションで 5 秒〜5 分）で自動保存します。
- 保存済みファイルは通知なしで上書き保存し、無題の文書は `%LOCALAPPDATA%\WordPadLite\recovery` に復元用 RTF を書き出します。

### ファイル形式
- **RTF** — 標準の保存形式。書式を保持したまま保存 / 再オープンできます。
- **TXT** — UTF-8（BOM 付き）/ CRLF で保存。
- **DOCX** — 本文テキストとページ設定の入出力に対応。
- **印刷設定** — 印刷前に用紙サイズ / 印刷の向き / 余白を指定するダイアログを表示し、その設定を反映した一時 RTF を既定の印刷アプリで開きます。部数は印刷ダイアログ側で指定します。

### 設定の保存先
`%LOCALAPPDATA%\WordPadLite\settings.ini` に、テーマ / 自動保存の有無と間隔 / 既定フォントとサイズ / クイック アクセス ツール バーの内容 / スペルチェック / トースト通知の有無 / アカウントのプロフィールを保存します。リボンの表示形式は `ribbon-mode.txt` に保存されます。

## 既知の制限

ネイティブ版は簡易実装のため、Word の高度な機能の一部は「準備中」のメッセージを表示します。

- DOCX は本文テキスト + ページ設定のみ（書式・表・画像は未対応）
- PDF 書き出し / ページ番号の埋め込み
- 差し込み印刷のデータベース接続、変更履歴の記録、翻訳 / 読み上げ
- 段落記号の表示、ナビゲーション ウィンドウ

これらは Web 版で利用できます。ネイティブ版では順次対応予定です。

# Web 版（ASP.NET Core）

SPEC.md（WordPad Lite 仕様書 v1.1.0）をもとに、**フェーズ 1 Core Editor（MVP）** から実装を進めています。

## 現在の実装

### UI / UX
- **Word を踏襲した基本レイアウト**
  - タイトルバー + クイック アクセス ツール バー（保存 / 元に戻す / やり直し）
  - ファイル / ホーム / 挿入 / レイアウト / 表示 のリボン構成
  - ホーム: クリップボード / フォント / 段落 / スタイル / 編集
  - 挿入: ページ / テーブル / 図 / リンク
  - レイアウト: 用紙サイズ / 向き / 余白 / ヘッダー / フッター / 段落
  - 表示: 読書モード / 定規 / 改行記号 / ズーム / テーマ
- **Fluent Design 風のモダン UI**
  - Mica / Acrylic 風の半透明サーフェス
  - Fluent 系 CSS トークン、角丸、Reveal 風ホバー
  - ライト / ダーク / システム テーマ
  - インライン SVG アイコン
  - Noto Sans JP を同梱（日本語フォントがない環境でも表示可能）
- コマンド パレット（Ctrl+K）
- ステータス バー（ページ / 行 / 文字数 / 選択文字数 / IME / ズーム）

### エディタ
- テキスト入力（日本語 IME 対応）
- 太字 / 斜体 / 下線 / 取り消し線
- フォント / サイズ / 文字色 / 背景色
- 段落揃え / インデント / 段落前後の間隔 / 箇条書き / 番号付け / 行間隔
- 見出しスタイル
- 検索 / 置換（自前のテキスト ノード検索）
- 画像 URL / ローカル画像の挿入、リサイズ、90° 回転、削除
- リンク挿入 / テーブル挿入
- 改ページ / 空白ページ挿入
- ドラッグ＆ドロップでファイルを開く
- 用紙設定（A4 / B5 / Letter / Legal、縦横、余白 1–50mm）
- ヘッダー / フッター / ページ番号の表示・PDF / DOCX への反映

### ドキュメント モデル / 履歴
- **AST ベースのドキュメント モデル**
  - Paragraph / Heading / Table / TextRun / ImageRun / List などのノード
  - `editorModel.js` に DOM ⇔ AST 変換を実装
- **Undo / Redo 1000 ステップ**
  - スナップショット スタック
  - 連続入力は 700ms 以内の変更を 1 ステップにまとめる
  - クイック アクセス ツール バーのボタン状態と連動

### ファイル形式
- **DOCX**
  - `DocumentFormat.OpenXml` + `AngleSharp` によるサーバー側変換
  - 見出し / 太字 / 斜体 / 下線 / 取り消し線 / 文字色 / 背景色 / フォント / サイズ
  - 段落揃え / 段落前後の間隔 / 箇条書き / 番号付きリスト / 表 / 改ページ
  - 用紙サイズ / 向き / 余白 / ヘッダー / フッター / ページ番号
  - ローカル画像（データ URL）の埋め込み
  - DOCX 読み込み時は本文・表・見出し・書式を HTML に変換
- **PDF**
  - `QuestPDF` によるサーバー側書き出し
  - 見出し / 太字 / 斜体 / 下線 / 取り消し線 / 文字色 / フォント / サイズ
  - 段落揃え / 段落前後の間隔 / 箇条書き / 番号付きリスト / 表 / 改ページ
  - 用紙サイズ / 向き / 余白 / ヘッダー / フッター / ページ番号
  - ローカル画像（データ URL）の埋め込み
  - `PdfPig` による簡易読み込み（ページごとのテキストを段落として取り込み）
- TXT / HTML / RTF / Markdown の読み込み
- TXT / HTML / RTF / Markdown の保存
- RTF は簡易パーサ、Markdown は簡易変換

### API
- `POST /api/docx/export` — HTML + ページ設定から DOCX を生成
- `POST /api/docx/import` — DOCX バイナリから HTML を生成
- `POST /api/pdf/export` — HTML + ページ設定から PDF を生成
- `POST /api/pdf/import` — PDF バイナリからテキスト HTML を生成

## 起動方法

```bash
cd WordPadLite
dotnet run --urls "http://localhost:5000"
```

ブラウザで `http://localhost:5000/` を開いて動作確認してください。

### フォントについて

`WordPadLite/wwwroot/fonts/` に Noto Sans JP（SIL Open Font License 1.1）を同梱しています。
Windows では Meiryo UI が優先され、Linux など日本語フォントがない環境では Noto Sans JP が使われます。
PDF 書き出し時も同じフォントを登録して日本語を描画します。
