# Word 2026 — リボン UI 仕様

Word 2026 のリボン構成。WordPad Lite のリボン設計の直接の参考とする。

---

## 1. 全タブ一覧

| 順序 | タブ名 | 主な用途 |
|------|--------|----------|
| 1 | ホーム | 書式設定（フォント、段落、スタイル） |
| 2 | 挿入 | 表、画像、図形、リンク、ヘッダー/フッター |
| 3 | デザイン | テーマ、色、フォント、透かし |
| 4 | レイアウト | 余白、方向、段組、配置 |
| 5 | 参考資料 | 目次、脚注、引用、キャプション |
| 6 | 差し込み文書 | 差し込み印刷、ラベル、封筒 |
| 7 | 校閲 | スペル/文法、翻訳、コメント、変更履歴 |
| 8 | 表示 | 表示モード、ズーム、ルーラー、マクロ |
| 9 | ヘルプ | 検索、サポート、バージョン情報 |

「ファイル」はリボンタブではなく、バックステージを開く特殊なタブ。

### 1.1 リボン上部のグローバル領域（全タブ共通）

| 要素 | 位置 | 内容 |
|------|------|------|
| ファイル | 最左 | バックステージを開く |
| QAT 風ボタン | タブ直下 | コメント（吹き出しアイコン）、編集ドロップダウン、共有（青ボタン） |
| リボン折りたたみ | 最右 | ▼ でリボン最小化 |

### 1.2 タイトルバー領域

| 要素 | 内容 |
|------|------|
| アプリ アイコン | 左端 |
| 自動保存 | トグル（オン/オフ） |
| 保存アイコン | 上書き保存 |
| 元に戻す/やり直し | ドロップダウン付き |
| ページ リサイズ | ドラッグ |
| 文書名 | 中央 |
| 検索 | 右端 |
| ユーザー アバター | 右端 |
| 最小化/最大化/閉じる | 右端 |

### 8.2 動的 UI

| 条件 | 表示される項目 |
|------|----------------|
| 100 文字以上入力後 | エディター スコア（右ペインに「エディター スコア / 100文字で計算」から実際のスコア表示に遷移） |
| スペルミスあり | スペル チェックで修正候補が提案される |
| 変更履歴 ON | 変更の追跡、変更履歴ペイン（左側: 「変更履歴 / 〇個の変更箇所」） |

### 8.3 [変更履歴] ウィンドウ

- リボン左側のペインとして表示される
- 「変更履歴」という見出しの下の「〇個の変更箇所」を展開可能
- スクロール可能

### 8.4 エディター ペイン（右側）

| セクション | 内容 |
|-----------|------|
| エディター スコア | 「100文字で計算」→ 100文字超えるとスコア表示に切り替え |
| 修正点 | スペル（チェック済み）、文法（チェック済み） |
| 表現や表記上の考慮点 | 「簡潔な表現」などの提案 |
| 類似性 | 「オンライン ソースとの類似性をチェックします。」 |
| インサイト | 「ドキュメントの統計情報」 |

## WordPad Lite 実装目標

| 優先度 | タブ |
|--------|------|
| 必須 | ホーム、挿入、レイアウト、表示、ファイル |
| 推奨 | デザイン、校閲、ヘルプ |
| 将来 | 参考資料、差し込み文書 |

### 実装上の参考ポイント

- ホームの右端に「音声」「エディター」「アドイン」の大ボタンがあるが、WordPad Lite では優先度が低い場合は省略可能
- デザイン タブの「テーマ/スタイルセット」ギャラリーは、マウスホバーでプレビュー表示するインタラクション
- エディター スコア ペインは右サイドバーとして実装する場合の参考になる（修正点 → 類似性 → インサイト のセクション構成）
