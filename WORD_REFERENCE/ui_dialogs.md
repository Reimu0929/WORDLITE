# Word 2026 — 詳細ダイアログ / ウィンドウ タブ仕様

リボンでは収まりきらない詳細設定を行うためのダイアログ群。WordPad Lite では、必要最低限のダイアログを実装し、Word 2026 の構成を参考にする。

---

## 1. フォント ダイアログ

画像: `04_dialog_font.png`

**起動方法**: `Ctrl+D` または ホーム タブ → フォント グループのランチャー

### 1.1 タブ構成

| タブ | 主な設定項目 |
|------|--------------|
| フォント | フォント名、スタイル、サイズ、下線、取り消し線、色、特殊効果 |
| 詳細設定 | 文字間隔、位置（上付き/下付き）、文字飾り |

### 1.2 主要項目（スクリーンショット確認済）

| 項目 | 内容 |
|------|------|
| 日本語用のフォント(I) | システムにインストールされた日本語フォント（デフォルト: `+本文のフォント - 日本語`） |
| 英数字用のフォント(E) | システムにインストールされた英数字フォント（デフォルト: `+本文のフォント`） |
| スタイル(Y) | 標準 / 斜体 / 太字 / 太字斜体 |
| サイズ(S) | 8pt 〜 72pt、または直接入力（デフォルト: 10.5） |
| フォントの色(C) | 自動 / テーマ色 / 標準色 / その他の色 |
| 下線(U) | (下線なし) / 単線 / 二重線 / 太線 / 一点鎖線 / 二重點線 / 点線 など |
| 下線の色(I) | 自動 / テーマ色 / 標準色 |
| 傍点 | (傍点なし) / 太線 / 点線 / 破線 |
| 文字飾り | □ 取り消し線 / □ 二重取り消し線 / □ 上付き / □ 下付き / □ 小型英大文字 / □ すべて大文字 / □ 隠し文字 |
| プレビュー | 選択したフォントのプレビュー表示（例: 「遊明朝」） |

> ⚠️ **日本語環境の特別な仕様**: 日本語版 Word では「日本語用のフォント」と「英数字用のフォント」が分離表示される。これは日本語と英数字で異なるフォントを使用する必要があるため。

### 1.3 下部ボタン

| ボタン | 機能 |
|--------|------|
| 既定に設定(D) | 現在の設定をデフォルトに設定 |
| 文字の効果(E)… | テキスト効果（影、輪郭、発光）ダイアログを開く |
| OK | 適用して閉じる |
| キャンセル | 変更を破棄して閉じる |

### 1.4 プレビュー フッター

- 選択したフォント名と説明テキストを表示
- 例: 「これは日本語用の本文のテーマ フォントです。現在の文書のテーマによって、使用されるフォントが決まります。」

## 2. 段落 ダイアログ

画像: 行間ドロップダウン `04_dialog_paragraph.png` から一部確認

**起動方法**: ホーム タブ → 段落 グループのランチャー

### 2.1 グループ構成

| グループ | 主な設定項目 |
|----------|--------------|
| インデントと行間隔 | 左/右インデント、特殊インデント（最初の行/ぶら下げ）、行間 |
| 改行とページ区切り | ページの先頭で改ページ、段落同士をくっつける、次の段落と結合など |
| 中文の版式 | 禁則処理、文字の組み方（日本語環境で表示） |

### 2.2 行間ドロップダウン（画像確認済）

| 項目 | 内容 |
|------|------|
| 1.0 | 単間（既定） |
| 1.15 | 1.15 行 |
| 1.5 | 1.5 行 |
| 2.0 | 2 行 |
| 2.5 | 2.5 行 |
| 3.0 | 3 行 |
| 行間のオプション… | 段落ダイアログの「インデントと行間隔」タブを開く |
| 段落前に間隔を追加(B) | 段落前にスペースを追加（クイック操作） |
| 段落後に間隔を追加(A) | 段落後にスペースを追加（クイック操作） |

### 2.3 段落ダイアログ（詳細設定）

| 項目 | 内容 |
|------|------|
| 左インデント | 段落全体の左側の余白 |
| 右インデント | 段落全体の右側の余白 |
| 特殊インデント | なし / 最初の行 / ぶら下げ |
| 値 | インデント量（文字数または cm） |
| 行間 | 単位行、1.5 行、2 行、固定値、倍数 |
| 段落前 / 段落後 | 段落間のスペース |

## 11. 検索と置換 ダイアログ

画像: `05_scenario_replace_dialog.png`

**起動方法**: `Ctrl+F` または `Ctrl+H`

### 11.1 構成

| タブ | 内容 |
|------|------|
| 検索 | 検索文字列のみ |
| 置換 | 検索文字列 + 置換後の文字列 |
| ジャンプ | 項目のジャンプ（ページ、脚注、検索結果など） |

| 項目 | 内容 |
|------|------|
| 検索する文字列(N) | 検索文字列入力 |
| オプション | あいまい検索(日) など詳細設定（オプション(>>) ボタンで展开） |
| 置換後の文字列(I) | 置換文字列入力（置換タブのみ） |
| 置換(R) | 1件ずつ置換 |
| すべての置換(A) | すべて置換 |
| 次を検索(F) | 次の一致を検索 |

## ダイアログ共通仕様

| 要素 | 仕様 |
|------|------|
| タイトルバー | 画面中央にダイアログタイトル、右端に `?`（ヘルプ）と `X`（閉じる） |
| ボタンの配置 | 右下に標準ボタン（OK / キャンセル）、その左に拡張ボタン（既定に設定 / 文字の効果 など） |
| サイズ | 画面の中央に固定サイズで表示、リサイズ不可 |
