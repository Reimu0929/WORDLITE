# Word 2026 — ミニ ツールバー仕様

テキストを選択した直後に、カーソル近くに半透明で表示されるフローティング ツールバー。WordPad Lite でも、頻出書式をすばやく適用できるように実装する。

---

## 1. 基本構造

| 項目 | 仕様 |
|------|------|
| 表示トリガー | テキスト選択直後（マウスボタンを離したタイミング） |
| 表示位置 | 選択範囲の直上、またはカーソル近傍 |
| 非表示条件 | マウスを離して一定時間経過、またはエディタ領域外に移動 |
| 外観 | 半透明の背景、角丸、小さめのアイコン |

> ⚠️ **ミニ ツールバーの画像キャプチャは未実施**。`ui_mini_toolbar.md` の記述は既存の一般的な構成を記載。

---

## 2. 標準的なボタン構成

左から右へ配置される。

| # | ボタン | 機能 | 備考 |
|---|--------|------|------|
| 1 | フォント | 現在のフォント名を表示、ドロップダウン | |
| 2 | フォント サイズ | サイズを表示、ドロップダウン | |
| 3 | 拡大 / 縮小 | サイズを段階的に変更 | |
| 4 | 太字 (Ctrl+B) | 太字 ON/OFF | |
| 5 | 斜体 (Ctrl+I) | 斜体 ON/OFF | |
| 6 | 下線 (Ctrl+U) | 下線 ON/OFF | |
| 7 | 中央揃え | 段落を中央揃え | |
| 8 | 箇条書き | 箇条書きの ON/OFF | |
| 9 | 段落番号 | 段落番号の ON/OFF | |
| 10 | フォントの色 | 文字色の変更 | プレビュー付き |
| 11 | 蛍光ペン | 背景色（ハイライト） | プレビュー付き |
| 12 | 書式のクリア | 選択範囲の書式を削除 | |
| 13 | スタイル | 標準/見出し 1 等を適用 | |

---

## 3. 選択状態による変化

| 選択対象 | 表示されるボタン |
|----------|------------------|
| テキスト | 書式全般（フォント、サイズ、太字、斜体、下線、色、整列、リスト） |
| 画像 | トリミング、サイズ変更、配置、代替テキスト |
| テーブル | 罫線、網かけ、セル結合、配置 |

---

## 4. インタラクション

| 操作 | 挙動 |
|------|------|
| マウスを近づける | 不透明に近づく |
| マウスを離す | 薄くなり、数秒後に消える |
| ボタンをクリック | 即座に書式を適用、ミニツールバーは維持 |
| Esc キー | ミニツールバーを閉じる |

---

## 5. WordPad Lite 実装目標

| 優先度 | 項目 |
|--------|------|
| 必須 | テキスト選択時の基本書式ボタン（太字/斜体/下線/フォントサイズ/色/整列） |
| 推奨 | 箇条書き、段落番号、蛍光ペン、書式のクリア |
| 将来 | 画像/テーブル選択時の専用ミニツールバー |
