# Word 2026 — コンテキスト メニュー（右クリック）仕様

文脈（選択対象）によって表示内容が変化する。WordPad Lite では、一般的なワープロで予想される最小構成を実装しつつ、Word 2026 と同等の項目を目標とする。

---

## 1. テキスト選択時

画像: `03_context_text.png`

テキストをドラッグまたはダブルクリックで選択した状態で右クリック。

### 1.1 メニュー項目（上から下へ）

| # | メニュー項目 | 備考 |
|---|--------------|------|
| 1 | 切り取り | Ctrl+X |
| 2 | コピー | Ctrl+C |
| 3 | 貼り付け | ドロップダウン: 元の書式を保持 / 書式を統合 / 画像として貼り付け / テキストのみ保持 |
| 4 | **貼り付けのオプション**（セクション） |  |
| 5 | 元の書式を保持 | 貼り付けオプション |
| 6 | 書式を統合 | 貼り付けオプション |
| 7 | 画像として貼り付け | 貼り付けオプション |
| 8 | テキストのみ保持 | 貼り付けオプション |
| 9 | フォント… | フォント ダイアログ |
| 10 | 段落… | 段落ダイアログ |
| 11 | **段落番号の続行** | ドロップダウン: リストの続行 / 番号付けを再開始 |
| 12 | **新しいコメント** | 選択範囲にコメント追加 |
| 13 | **翻訳** | 選択テキストの翻訳ペイン |
| 14 | **シノニム** | 類義語の提案（選択語のコンテキスト メニューに出現） |
| 15 | **書式だけ貼り付け** | ドロップダウン: 書式のコピー元を保持 |
| 16 | **すべて選択** | Ctrl+A |

### 1.2 ドロップダウン構成

**貼り付け**:
- 元の書式を保持（アイコン付き）
- 書式を統合（アイコン付き）
- 画像として貼り付け（アイコン付き）
- テキストのみ保持（アイコン付き）

**段落番号の続行**:
- リストの続行（現在番号の次へ）
- 番号付けを再開始（1 から再始動）

> ⚠️ **セクション区切り**が存在: 「切り取り/コピー/貼り付け」→ 区切り → 「貼り付けのオプション」→ 区切り → 「フォント/段落/段落番号の続行」→ 区切り → 「新しいコメント/翻訳/シノニム/書式だけ貼り付け/すべて選択」

## WordPad Lite 実装目標

| 優先度 | 実装対象 |
|--------|----------|
| 必須 | テキスト選択時の基本メニュー（切り取り/コピー/貼り付け/フォント/段落/リンク/すべて選択） |
| 必須 | 画像選択時の基本メニュー（切り取り/コピー/貼り付け/サイズとプロパティ/回転） |
| 推奨 | テーブル用メニュー（行/列の挿入・削除、セル結合/分割） |
| 将来 | スペル/文法候補、翻訳、シノニム、エディター スコア |
