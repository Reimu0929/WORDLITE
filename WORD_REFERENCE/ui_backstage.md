# Word 2026 — バックステージ（ファイル メニュー）仕様

Word 2026 の「ファイル」タブを押すと表示される全画面メニュー。WordPad Lite の「ファイルメニュー / オプション」設計の参考とする。

---

## 1. 全体構造

| 要素 | 仕様 |
|------|------|
| 左側パネル | ナビゲーション メニュー（縦一覧、アイコン付き） |
| 右側パネル | 選択した項目に対応するコンテンツ |
| タイトルバー | 濃いブルー背景（通常時と同じ色）、文書名表示 |
| QAT / リボン | 非表示 |
| 戻るボタン | 左メニュー最上部に ← （バックステージ終了） |

### 1.1 戻るボタン（左メニュー最上部）

| 要素 | 仕様 |
|------|------|
| アイコン | 矢印（←） |
| 位置 | 左メニューの一番上（常に最上部固定） |
| 挙動 | クリックで通常のリボン表示に戻る |

---

## 2. 左側メニュー項目（スクリーンショット確認済）

**画像**: `02_backstage_home.png`、`02_backstage_新規.png`

上から下へ順に配置される。

| # | 項目 | 右側の主な内容 |
|---|------|----------------|
| 1 | **ホーム** | 最近使ったファイル、新規作成、開く |
| 2 | **新規** | テンプレート一覧、検索、オンラインテンプレート |
| 3 | **開く** | 最近、OneDrive、SharePoint、PC、参照 |
| 4 | **共有** | OneDrive/SharePoint リンク、メール、共同編集 |
| 5 | **情報** | 文書のプロパティ、保護、バージョン管理、ファイルサイズ |
| 6 | **上書き保存** | 現在のファイルへ上書き保存 |
| 7 | **名前を付けて保存** | 場所・ファイル名・形式の選択 |
| 8 | **印刷** | プレビュー、プリンター選択、印刷設定 |
| 9 | **エクスポート** | PDF/XPS の作成、変更履歴 |
| 10 | **閉じる** | 文書を閉じる（アプリは終了しない） |
| 11 | **アカウント** | ユーザー情報、Office 製品情報、テーマ |
| 12 | **その他...** | オプション、など追加項目 |

> ⚠️ **「共有」の位置**: 既存テンプレートでは「情報」より下だったが、Word 2026 では「情報」より上に配置されている。
> 
> ⚠️ **「上書き保存」の追加**: 既存テンプレートに無かったが、画像で確認された。
>
> ⚠️ **「その他...」の追加**: 左メニュー最下部に追加項目（オプション等）へのエントリー ポイント。

### 2.1 メニュー アイコン

| 項目 | アイコン |
|------|----------|
| ホーム | 家アイコン |
| 新規 | ＋（プラス） |
| 開く | ファイル（フォルダ） |
| 共有 | ファイルと矢印 |
| 情報 | i（情報） |
| 上書き保存 | ディスクレット |
| 名前を付けて保存 | ディスクレットとペン |
| 印刷 | プリンター |
| エクスポート | 矢印 |
| 閉じる | フォルダ（閉じた状態） |
| アカウント | 人物アイコン |
| その他... | 00（数字） |

## 3. 各ページ詳細

### 3.1 ホーム

**画像**: `02_backstage_home.png`

| 要素 | 内容 |
|------|------|
| 新規作成 | 青い「空白の文書を新規作成」ボタン（トップ） |
| 最近使ったファイル | リスト形式（ファイル名 / 保存場所 / 変更日） |
| | タブ: 最近使ったアイテム / お気に入り / 自分と共有 |
| | サーチボックス: 「ファイルを検索してください」 |
| | サイドリンク: 「その他の文書 →」 |

**最近使ったファイル リスト**:

| 列 | 内容 |
|----|------|
| 名前 | ファイル アイコン（W ロゴ）+ ファイル名 + 保存場所 |
| 変更された日 | 日付（例: 9月29日） |

### 3.2 新規

**画像**: `02_backstage_新規.png`

| 要素 | 内容 |
|------|------|
| タブ | 「新規」にチェックボックス付き |
| テンプレート ギャラリー | 白紙の文書 / Word へようこそ / はじめての目次作成チュートリアル / シングル スペース (空白) / 日本語の履歴書 / 表紙のある学生レポート |
| | カテゴリ タブ: カテゴリごとにフィルタ |
| | サーチボックス: 「ファイルを検索してください」 |
| | リンク: 「その他のテンプレート →」 |
| 最近使ったファイル | ホームと同じリスト |

## 4. インタラクション

| 操作 | 挙動 |
|------|------|
| 左メニュー クリック | 右側コンテンツを切り替え |
| 戻るボタン（←） | バックステージを閉じる |
| Esc キー | バックステージを閉じる |
| タブ外エリア | 通常のリボン表示に戻る（Esc と同様） |

| 将来 | 共有、エクスポート、テンプレート ギャラリー |
