# Word 2026 完全キャプチャ チェックリスト

「Word に慣れた人がすぐに使える軽量エディタ」を目指すため、Word 2026 の UI/UX を網羅的に記録するためのチェックリスト。

一部の UI は**条件を満たさないと表示されない**（例：エディター スコアは 100 文字以上入力後）ため、単純な自動撮影だけでは不十分。
以下のカテゴリごとに、**「対象ウィンドウ/領域」「撮影条件」「備考」**を明確にして記録する。

---

## 1. アプリケーション フレーム（文書の有無に関係なく表示）

| # | 対象 | 条件 | 備考 |
|---|------|------|------|
| 1.1 | タイトルバー | 通常表示中 | 文書名、未保存インジケーター、QAT、最小化/最大化/閉じるボタン |
| 1.2 | クイック アクセス ツールバー（QAT） | 既定の状態 + カスタマイズ後 | 既定項目と、追加可能なコマンド一覧 |
| 1.3 | ステータスバー | 通常表示中 | ページ、文字数、言語、校正、モード、ズームスライダー |
| 1.4 | スクロールバー / ルーラー | 表示タブでルーラー ON | 水平・垂直ルーラーの表示有無、目盛り |
| 1.5 | ウィンドウ テーマ | ライト / ダーク / システム | 各テーマでのフレーム色、アクセント色、用紙色 |

## 4. リボン UI（文書編集時）

### 4.1 タブ一覧

| タブ名 | 備考 |
|--------|------|
| ホーム | クリップボード、フォント、段落、スタイル、編集 |
| 挿入 | 表、画像、図形、グラフ、リンク、ヘッダー/フッターなど |
| デザイン | テーマ、スタイルセット、色、フォント、段落間隔、透かし |
| レイアウト | 余白、方向、サイズ、段組、改ページ、配置 |
| 参考資料 | 目次、脚注、引用文献、キャプション、索引、参照 |
| 差し込み文書 | 差し込み印刷、ラベル、封筒 |
| 校閲 | スペル チェック、エディター、翻訳、コメント、変更履歴、比較、保護 |
| 表示 | 表示モード、ズーム、ルーラー、グリッド線、ナビゲーション ウィンドウ、マクロ |
| ヘルプ | 検索、サポート、フィードバック、バージョン情報 |

### 4.2 各タブの記録項目

| # | 対象 | 条件 | 備考 |
|---|------|------|------|
| 4.2.1 | タブ全体 | タブをクリックした直後 | グループ名とボタン配置の全体像 |
| 4.2.2 | ドロップダウン / ギャラリー | 各 SplitButton / ドロップダウンを展開 | フォント、スタイル、色、箇条書き、テーマなど |
| 4.2.3 | スタイル ギャラリー | ホーム タブのスタイルを展開 | 標準、見出し 1〜9、タイトルなど |
| 4.2.4 | コマンド パレット | Ctrl+K | コマンド検索 UI |
| 4.2.5 | リボンの折りたたみ | タブのみ表示状態 | 折りたたみ時の見た目 |

## 6. 動的/条件付き UI（最重要）

これらは自動撮影だけでは捉えきれないため、**シナリオ実行後に撮影**する。

| # | 対象 | 前提条件 | 撮影タイミング |
|---|------|----------|----------------|
| 6.1 | エディター スコア | **100 文字以上入力** | 校閲タブを開いた状態で撮影 |
| 6.2 | スペル/文法の赤字波線 | 明らかなミスを含むテキスト入力後 | ミス部分をホバー/クリック |
| 6.3 | 翻訳 / 言語の提案 | 英語等を含む文書 | 校閲タブの翻訳を開いた状態 |
| 6.4 | 変更履歴の表示 | 変更履歴を ON にして編集後 | 校閲タブの変更履歴グループ |
| 6.5 | コメント ウィンドウ | コメントを 1 件追加後 | 校閲タブのコメント表示 |
| 6.6 | ナビゲーション ウィンドウ | Ctrl+F または 表示タブ | 見出し/ページ/結果タブ |
| 6.7 | 検索パネル | Ctrl+F | ドキュメント内検索 UI |
| 6.8 | 置換ダイアログ | Ctrl+H | 検索と置換 UI |
| 6.9 | ファイルの自動保存 / 復元 | 自動保存 ON で編集後 | タイトルバー、情報ページ |
| 6.10 | 読み取り専用モード | 読み取り専用ファイルを開いた状態 | リボンの編集不可表示 |
| 6.11 | 保護されたビュー | ネットワークから開いたファイル | 黄色い警告バー |
| 6.12 | 互換性モード | 古い形式のファイルを開いた状態 | タイトルバー、情報ページ |

## 7. スクロール/展開が必要な UI

| # | 対象 | 対応 |
|---|------|------|
| 7.1 | リボンのドロップダウン ギャラー | マウスでスクロールしながら複数枚撮影 |

| 7.4 | スタイル ウィンドウ | 全スタイルが表示されるまでスクロール |
| 7.5 | 長いコンテキスト メニュー | 下方向にスクロールして残りを撮影 |

## 11. シナリオ別キャプチャ（手動 or 追加スクリプト）

| シナリオ | 操作 | 記録対象 |
|----------|------|----------|
| S-01 | 100 文字以上入力後、校閲タブを開く | エディター スコア、校正メニュー |
| S-02 | 意図的なスペルミスを入力後、ホバー | 波線、修正候補 |
| S-03 | 画像を挿入し、サイズ変更ハンドルを表示 | 画像ツールの書式タブ |
| S-04 | 表を挿入し、セル内で右クリック | 表のデザイン/レイアウトタブ、コンテキストメニュー |
| S-05 | ヘッダーをダブルクリック | ヘッダー/フッター ツールの「デザイン」タブ |
| S-06 | Ctrl+F → 検索語を入力 | ナビゲーション/検索ペイン |
| S-07 | 表示モードを切り替え | 各モードの表示状態 |
| S-08 | 変更履歴を有効にしてテキストを削除 | 削除線、吹き出し、変更履歴ペイン |
| S-09 | コメントを追加 | コメント吹き出し、コメントペイン |
| S-10 | ネットワークファイルを開く | 保護されたビューの警告バー |

## 12. 記録形式

各キャプチャは以下のメタデータと共に保存する。

```text
WORD_REFERENCE/
├── captures/
│   ├── 01_app_frame/
│   ├── 02_start_screen/
│   ├── 03_backstage/
│   ├── 04_ribbon/
│   ├── 05_editor/
│   ├── 06_dynamic/
│   ├── 07_dialogs/
│   └── 08_scenarios/
├── capture_checklist.md   # このファイル
├── ui_ribbon.md           # リボン UI 構造化メモ
├── ui_backstage.md        # バックステージ構造化メモ
├── ops_shortcuts.md       # ショートカット一覧
├── spec_defaults.md       # デフォルト値・仕様
└── visual_design.md       # 色・デザイン
```
